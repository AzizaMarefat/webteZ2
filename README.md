# WEBTE1 – Zadanie 2
## Obedové menu v okolí fakulty

Autor: Aziza Nazari  

https://webte1.fei.stuba.sk/~xnazari/z2/


### Popis projektu
Webová aplikácia zobrazuje obedové menu troch reštaurácií v okolí FEI STU. Umožňuje výber dňa, filtrovanie reštaurácií, obnovenie menu a zobrazenie cien, alergénov a gramáží.

### Zdroje údajov
- [Reštaurácia DRAG](https://www.restauracia-drag.sk/denne-menu)
- [Eat & Meet](https://eatandmeet.sk/tyzdenne-menu)
- [Družba Cantina](https://www.druzbacatering.sk/jedalny-listok/)
